# Step 1 — Triage референсів (20–25 хв)

Мета: з ~158 пінів дійти до **≤30 Keep** і **3–4 кластерів**, без аналізу «чому».

## 0. Підготовка

1. Експортуй / збережи кандидати в `references/_inbox/` **або** одразу сортуй у Pinterest sections.
2. Фінальні Keep клади в `references/keep/`.
3. Не створюй папку `References` (лише `references/`) — Windows case-insensitive.

## 1. Швидкий прохід (таймер 20 хв)

Для кожного піна **один** жест:

| Жест | Куди |
|------|------|
| Keep | `references/keep/` |
| Skip | `references/skip/` або Pinterest hide |
| Later | `references/later/` (макс. **15**) |

Правила:

- Не аналізуй. Тільки «вау / ні / сумнів».
- Skip: неон, дефолтний SaaS purple, середньовічний Данте, випадкове збереження.
- Якщо Keep > 40 після проходу — другий раунд: «лишаю лише 16».

## 2. Розклад у кластери (5–10 хв)

Копіюй топи з `keep/` у:

| Кластер | Коли |
|---------|------|
| `A-atmosphere-cosmic` | шари світів, nebula, золоті кільця |
| `B-atmosphere-organic` | дерева, бібліотека, прірва, тепло-темна матерія |
| `C-atmosphere-modern-surreal` | сучасний предмет + епічне небо / портали |
| `D-product-ui` | реальний UI (cards, lobby, grids, posters) |

Один пін → один кластер (де сильніше відчуття).
З кожного кластера лиши **3–5 найсильніших**.

Онови [`../references/INDEX.md`](../references/INDEX.md).

## 3. Обовʼязковий gap: product-UI

Якщо `D-product-ui` порожній або < 8 файлів — **не йди в Style Lock**.

Добери окремо (Pinterest / Mobbin / screenshots):

- [ ] dark editorial app
- [ ] achievement / collectible grid
- [ ] event poster
- [ ] multiplayer lobby + code/QR
- [ ] host live console
- [ ] solo training UI
- [ ] mobile waiting state
- [ ] typography-led landing

## 4. Moodboard колажі

Див. [`../moodboards/README.md`](../moodboards/README.md) — по колажу на напрямок A/B/C (+ окремо D для UI density).
