## 01 — Home (`/`) — **UX LOCKED** (ревізія 2026-10-07)

> Повна фіксація: [`home-ux-locked.md`](home-ux-locked.md)  
> Базовий макет: [`../concepts/d01-hub/2026-10-07-portal-v1.png`](../concepts/d01-hub/2026-10-07-portal-v1.png) (фон дзеркалити)  
> Окремого лендінгу немає — це стартова сторінка для гостя й авторизованого.

**Ієрархія:** бренд + профіль → банер-слайдер → портал із трьох дверей.

- **Header:** зліва лише «Божественна комедія»; справа профіль — гість: іконка → вхід; авторизований: аватар → профіль. Без nav-меню, пунктів Рай/Чистилище/Пекло, пошуку, «Увійти», сайдбару, CTA в шапці.
- **Банер:** обовʼязково; слайди з адмінки (картинка + посилання; заголовок / опис / дата опційно); автозміна ≈5 с + dots/arrows; «Деталі». Немає слайдів → банер схований.
- **Троє дверей** (клімат без лейблів; без journey-бару):
  - **Ліві (світлі):** Досягнення (± «124 з 400») · Усі ігри
  - **Центральні (холодні):** Турніри · Події
  - **Праві (вогняні):** Стендап · Імпровізація · Теорія (без чеклістів/прогресу практики)
- Гість бачить усе; авторизацію вимагає цільова поверхня, не Home.
- **Адаптив:** desktop — панорама; tablet — cover + вузли біля дверей; mobile 390 — банер угорі, далі три секції дверей стовпчиком (2 · 2 · 3). Деталі — `home-ux-locked.md` § Адаптив.
- Hub, не dashboard; «Популярні ігри» лише опційно під порталом.

Промпт: `prompts/03-d-product-ui/d01-hub.md` (v6) · Spec: F-2.2

## 05b — Ачівки (категорія)

## 05b2 — Грішники (приватна категорія)

- Та сама оболонка, що F-4.3: DC-NAV-001, back «Досягнення», пошук + Level + Status, картки DC-ACH-002/003
- Фон — `DC-ACH-012` (кривавий місяць), не дерево Раю. Клімат Color mode `Sinners`: темне вино на картках, червоний контур. Кнопки і тип ті самі
- H1 «Грішники» + прогрес «визнано / усього» (1 / 3). Без pill «Запропонувати ачівку»
- Privacy — один рядок заввишки з пошуком: «Твої гріхи бачиш тільки ти і ніхто інший.» Desktop — у рядку пошуку, праворуч від фільтрів. Mobile 390 — над пошуком, на всю ширину
- Без сесії grid не показувати — банер «Сесію завершено» + «Увійти»
- Довгий каталог (до кількох десятків, без пагінації API): перші картки + ряд скелетонів, решта довантажується ліниво
- Категорія недоступна і системна помилка — без privacy notice

Spec: F-4.13

## 05c — Запропонувати ачівку (модал)

- Overlay поверх поточної поверхні каталогу (F-4.2 або F-4.3), без окремого маршруту
- Форма `DC-ACH-007`: наявна категорія (вкл. «Грішники») або нова назва · текст ≤200 · складність · «Надіслати» / «Скасувати»
- Стани: loading категорій · default · prefill з categoryId · validation · system error (дані збережено, «Спробувати ще») · success pending · unauthorized → F-1.2 (форму не показувати)
- Тон «ти»; модал `zone/card` + `zone/card-border` на атмосфері Раю

Spec: F-4.10

## 05d — Підтвердити / скасувати ачівку (на картці списку)

- Не окремий маршрут і не сторінка деталей: write з картки `DC-ACH-002` на F-4.3
- Not Confirmed → «Підтвердити»; Confirmed → галочка + тиха icon-кнопка скасування (без тексту «Підтверджено», без модалки)
- Після успіху: оновлені статус, % «Виконали N%», прогрес категорії X / Y + toast `DC-FB-001` (400ms поява, 2.4s hold, 150ms зникнення)
- Помилки 403 / 404 / 500 — той самий toast; статус картки не змінюється
- Сесія і refresh-fail лишають банер з CTA («Увійти» / «Оновити»)
- «Підтвердити» притиснуте вправо в meta, як галочка + cancel
- Карми пекла за скасування немає

Spec: F-4.6

## 05e — Визнати / скасувати гріх (на картці «Грішники»)

- Не окремий маршрут: write з картки `DC-ACH-002` на сітці F-4.13 (атмосфера `DC-ACH-012`, privacy, без «Запропонувати»)
- Not admitted → «Визнати»; Admitted → галочка + тиха icon-кнопка скасування (без тексту «Визнано», без модалки)
- Після успіху: оновлені статус, «Виконали N%», прогрес X / Y + toast `DC-FB-001`
- 404 / 403 / 500 — той самий toast; статус картки не змінюється
- Сесія і refresh-fail — банер `DC-FB-002` з CTA («Увійти» / «Оновити»)
- Карми пекла за скасування немає

Spec: F-4.14

## 07 — Лобі Host (1440)

Один приклад для генерації. Стан: Never Have I Ever, четверо в кімнаті, не всі готові, старт неактивний. Без модалки на цьому кадрі.

- Кадр 1440 × hug. Шапка `DC-NAV-001`. Фон нейтральний темний, без `DC-ROOM-026` і без категорійного чіпа
- Заголовок лише «Лобі Never Have I Ever». Чіп категорії («Алкогольні») не малювати
- `DC-ROOM-028` Role=Host: QR, `ABC123`, іконка копії, «Telegram», «WhatsApp»; без іконки системного поширення; справа (праворуч ряду) червона «Скасувати кімнату»
- `DC-ROOM-030`: ліворуч гравці, праворуч налаштування і старт. Не стовпчик «склад → налаштування → старт на всю ширину»
- Лічильники окремо: «Учасники 4 / 20» і «Готові 3». Повний склад — «Учасники 20 / 20». Сітка по 3 з `DC-ROOM-029`
- Картки: Вергілій · ведучий · кругла галочка `DC-ACH-003`, без кіка; Марко і Беатріче · галочка · іконка кіка; Данте · іконка очікування `DC-ROOM-027` Waiting · іконка кіка
- Права секція, `Game=NHIE`: блок/вкладка коротких правил гри; «Категорії · Подорожі, Стосунки», «Складність · Важко», «Питань · 10», «Таймер · Без таймера», кнопка «Налаштування», під нею «Почати гру» Size L неактивна
- Не малювати: порожній абзац, картку обраної гри, URL рядком, hero-код, слова «Виключити» і «Готовий», іконку системного поширення
- Модалки не на цьому кадрі. Кік відкриває `DC-FB-003`: «Виключити Данте?» / кімната і код лишаються / «Виключити» + «Скасувати». Скасування кімнати — теж `DC-FB-003`: кімната закриється для всіх, код перестане працювати

Spec: F-5.2 · F-5.7 · F-5.9 · F-5.12 · F-5.19 · F-6.1

## 08 — Лобі Player (390)

- Той самий заголовок і `DC-ROOM-028` Role=Player: справа «Покинути кімнату» тієї ж висоти, що іконки ряду, не Size L
- Сітка `DC-ROOM-029` без кіка і без «Скасувати кімнату»
- Велика дія Size L — «Підтвердити готовність»; після неї «Ти підтвердив готовність» і «Скасувати готовність». Не ставити її в один ряд із «Покинути»
- Налаштування лише для читання, без кнопки «Налаштування» і без старту

Spec: F-5.3

## 12 — Власний профіль (`/profile`)

- Шапка як Home: зірка + «Божественна комедія» + аватар (DC-NAV-001), без back, без зонного меню
- H1 «Профіль»
- Шапка профілю `DC-AUTH-003`: аватар · нікнейм · email (лише власнику); праворуч у тому ж блоці «Вийти» і «Деактивувати акаунт». **Немає** «Редагувати» (F-3.2) і стрічки статистики (F-3.4)
- Вітрина `DC-AUTH-006`: лише Completed; картка = назва · категорія · складність · «Виконали N%»; власник бачить «Грішники». Без confirm/cancel і без «Усі ачівки»
- Порожня вітрина — пояснення, не помилка. Без сесії — банер + «Увійти», дані профілю не показувати. 500 — `DC-FB-006` + «Спробувати ще»
- «Вийти» без діалога → головна як гість (F-1.3). «Деактивувати акаунт» — діалог підтвердження → soft delete (F-1.4). Немає на loading / session / error

Spec: F-3.1 · F-1.3 · F-1.4

## 13 — Редагування власного профілю (`/profile/edit`)

Spec: F-3.2
