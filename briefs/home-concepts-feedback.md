## По концептах

### 1) «Три світи. Один шлях» (Pinterest / map fantasy)

**Подобається**
- Гармонійне перетікання пекло → чистилище → рай одним простором.
- Відчуття **карти**: точки розкидані просторово, не лише в рівній сітці карток.
- З цим варіантом **можна працювати** як з візуальним напрямом (більш просторово / «пуяльно» map-like).

**Не подобається / прибрати**
- Явні назви зон «Пекло», «Чистилище», «Рай» — зайві: бренд уже каже про Dante; зони = колір + атмосфера.
- Немає **банера з афішами** — на Home він обовʼязковий.
- Верхня nav + пошук + «Увійти» — на старті обійти; лишити профіль.
- Нижня рисочка-прогрес і копірай «Твій шлях триває» / подібні фрази — прибрати.

**Як перекласти на продукт (не Dante-лейбли)**
| Зона (атмосфера) | Замість поетичних вузлів | Куди веде |
|------------------|-------------------------|-----------|
| Світла / «рай» | Острівець → **Досягнення**; інший → **Ігри** (без акценту «соціальні» в назві вузла) | D03 / D04 |
| Середина / «чистилище» | Вузли → конкретні **івенти / турніри** (стендап-івент, турнір стрімерів тощо) | D02 / D08 |
| Темна / «пекло» | Вузли → **Імпровізація · Стендап · Теорія** | D09 |

---

### 2) «Темний портал ігор та хаосу» (три ворота в залі)

**Подобається — сильний Keep-напрям**
- Головна картинка з **трьома воротами**: холодне / золоте сонце / темне — зони **не названі** і виглядають природно.
- Атмосфера «вау», органічно під продукт.
- Ідея секції **«Популярні ігри»** — ок як опція **під** блоком трьох напрямків, не замість нього.

**Не подобається / прибрати**
- Пошук — не потрібен на Home.
- **Лівий сайдбар** — зайвий обʼєм; не використовувати цей підхід. Достатньо профілю.
- Не вистачає шару **афіш**: навіть на цій картинці можна «причепити» банер; бажано **одна велика афіша на ширину**, ротація ≈5 с з адмінки.

**Ідея на потім (опційно, не lock)**
- Під порталами — «дерево» / гілки, що ведуть у Досягнення·Ігри / Турніри / Стендап·Імпро·Теорія; «Популярні ігри» ще нижче.

---

### 3) «Усе в одному місці» (три вертикальні картки + dense top nav)

**Подобається**
- Читабельна трійка напрямків (ігри/досягнення · події · сцена) як каркас IA — уже в lock.

**Не подобається / прибрати**
- Dense верхня таба (Головна / Ігри / Події / Спільнота), пошук Ctrl+K, «Увійти» — як у матриці вище.
- Хочеться **більше різноманітних** візуальних варіантів далі — не зациклюватись на одному «elegant dark cards» прийомі.

---

### Інші варіанти в тій самій серії (коротко)

Концепти з каруселлю зверху + три колонки знизу (скло / епічна панорама / театральний абсурд) — **ближчі до locked IA**.  
Тримати: header мінімальний · афіші зверху · три зони без Dante-лейблів.  
Не тягнути: сайдбар, пошук, journey-бар, музейну «тиху розкіш» як єдиний mood (див. art note у lock).

### 4) portal-v1 — макет PO (обрано базою)

Файл: [`../concepts/d01-hub/2026-10-07-portal-v1.png`](../concepts/d01-hub/2026-10-07-portal-v1.png) · фон: [`../references/keep/home-portal-bg.png`](../references/keep/home-portal-bg.png)

**Keep**
- Зал із трьома дверима як цілий екран: двері = навігація, без підписів зон.
- Банер-слайдер поверх фону: дата-пігулка · заголовок · 2 рядки · «Деталі» · стрілки + dots.
- Вузли-плашки (іконка + текст + стрілка) біля своїх дверей; header — wordmark + аватар.

**Виправити**
- Мапінг дверей на макеті дзеркальний до lock (імпро/теорія/стендап біля вогню **зліва**, досягнення/ігри біля золота **справа**). Lock: світлі двері зліва → **дзеркалимо фон**, вузли лишаються біля «свого» клімату.
- Центральні двері — лише «Турніри» і «Події» (на макеті так і є) — список подій із датами не повертати.
- Профіль: потрібен ще кадр гостя (нейтральна іконка замість аватара).
- Адаптив — окремі кадри tablet і mobile 390 за `home-ux-locked.md` § Адаптив.

## Рішення для наступних генерацій

1. **IA не ламати** — див. `home-ux-locked.md`.
2. **Art direction пріоритет:** просторова карта / панорама / **три ворота без підписів**; клімат зон = навігація.
3. **Афіша обовʼязкова** — бажаний UI: один full-width ротаційний постер (CMS); 3-up стрічка допустима як альтернатива, але не замість промо-шару.
4. **Chrome:** wordmark + профіль; без nav-меню, пошуку, сайдбару, «Увійти».
5. **Різноманітність:** наступні концепти свідомо різні за характером (сатира / сцена / абсурд / map), при тій самій структурі блоків.
6. **«Популярні ігри»** — тільки опційний низ; не обовʼязковий для прийняття Home.
