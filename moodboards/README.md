# Moodboards

Колажі для ChatGPT Astra (і для себе). Не Figma-дизайн — лише візуальний бриф.

## Як зібрати

1. Візьми **топ-4** з одного кластера (`references/clusters/A|B|C|…`).
2. Зліпи сітку **3×3** або **2×2** (Photos / Figma board / PowerPoint — байдуже).
3. Збережи сюди:

| Файл | Зміст |
|------|--------|
| `moodboard-A-cosmic.png` | Кластер A |
| `moodboard-B-organic.png` | Кластер B |
| `moodboard-C-modern-surreal.png` | Кластер C |
| `moodboard-D-product-ui.png` | Кластер D (обовʼязково для Astra UI) |

4. У Astra прикріпи **відповідний moodboard + D**, не всю дошку.

## Правила

- Один moodboard = один напрямок відчуття.
- Підписи на колажі не обовʼязкові.
- Якщо колаж змішав fantasy layout + UI — рознеси: fantasy лишається в A/B/C, UI тільки в D.

## Після Style Lock

Переможний moodboard можна скопіювати як `moodboard-LOCKED.png` і більше не міняти mid-flight.
