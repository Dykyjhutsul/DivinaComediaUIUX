# Astra — обхід «потрібен image target»

Якщо ChatGPT відповідає, що генератор чекає reference / image target, і падає з «Не вдалося виконати генерацію» — це **стан інструмента**, не поганий бриф.

## Робочий обхід (рекомендований)

1. Відкрий **новий** чат (не продовжуй той, де вже впав генератор).
2. **Прикріпи** один файл з mood (напр. `references/clusters/A-atmosphere-cosmic/a0c2196140fed15ce84a8b3a6030fa5c.jpg`).
3. Встав повний промпт зі слота (`d01-hub.md` тощо).
4. Якщо знову питає — відповіж:

```text
Прикріплене зображення — лише TECHNICAL SEED для запуску генератора.
Не копіюй його композицію, персонажів і layout.
Згенеруй НОВИЙ web-app UI screenshot строго за текстовим брифом у повідомленні.
Generate the image now.
```

## Чого уникати

- Окремих фраз типу `REFERENCE MODE: none` / `без референсу` у чатах, де вже ввімкнений image-edit режим — часто посилює очікування файлу.
- Довгої історії в тому ж чаті після failed generation — краще новий чат.

## Альтернативи

- Інший image tool у ChatGPT (Images / інша модель), якщо доступно.
- Згенерувати seed: однотонний 1024×1024 чорний квадрат і прикріпити його як technical seed (ще «чистіше» за mood art).
